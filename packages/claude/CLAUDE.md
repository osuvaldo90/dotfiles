I typically use jj instead of git. There are many skills, instructions, etc. that will instruct you to use git. Instead, IT IS VERY IMPORTANT that you use the jj equivalent. After completing work that is going to be committed and handing control back to me you should ALWAYS leave the repository with an empty working copy on top of the work you just did.

Prefer to refer to commits by their jj change ID instead of the git commit id.

When a branch, bookmark, PR, etc. conflicts with the main branch ALWAYS rebase. Do not use merge commits to merge main into the branch.
